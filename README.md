## 📖 Data Structures

### Stack

Stack follows **LIFO (Last In, First Out)** principle.

Main operations:

* Push
* Pop
* Peek
* Display

### Queue

Queue follows **FIFO (First In, First Out)** principle.

Main operations:

* Insert
* Delete
* Display

### Deque

Deque stands for **Double Ended Queue**.

Insertion and deletion can be performed from both ends.

### Priority Queue

In a Priority Queue, elements are processed according to their priority.

### Linked List

A Linked List is a dynamic data structure consisting of nodes connected using pointers.

Types included:

* Singly Linked List
* Doubly Linked List
* Circular Linked List
* Singly Circular Linked List
* Doubly Circular Lined List
